# Crimson Desert Telemetry 2.2.15

Fixes **Stale Data** after switching playable characters. CDT now reads facing
from the character you control, so Kliff, Oongka and Damiane use the same pose
validation. While a switch is in progress, CDT discards samples that mix data
from two characters and resumes when it reads a valid pose.

The owner confirmed the fix with the production-profile preview on Steam build
**26776744** (EXE **1.0.0.3732**). The API schema is unchanged.

With the game closed, import **CrimsonDesertTelemetry-v2.2.15-ModManagers.zip**
through your mod manager. Keep the package's files together. Requires an **x64
ASI loader** and the **.NET 8 ASP.NET Core Runtime x64**.
Compatible with **CrimsonHue 2.0.0**.

[Installation guide](https://github.com/ZappendusterFX/CrimsonDesertTelemetry/tree/v2.2.15#install-or-upgrade)
