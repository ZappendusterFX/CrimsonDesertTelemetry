# Crimson Desert Telemetry 2.2.6

Restores telemetry for **Crimson Desert patch 2.04.05**, Steam build **26361232**
(EXE **1.0.0.3479**, Windows x64), verified with **Charting the Unknown** installed.

- Restores player and render-camera data after the engine layout change.
- Restores paired filtered light capture and the all-around engine-light input,
  including sources behind the camera.
- Restores global sky, camera-local sky visibility and the local ambient estimate.
- Restores per-light physics `clear` / `blocked` / `unknown` results using the new
  build's natural query context. Exact EXE, hook/context, collector, control replay,
  lifetime, time-budget and freshness checks remain enforced.

The existing HTTP/WebSocket API, schema 1.6, INI options, HUD/markers/radar and
optional separate CrimsonHue integration are retained. Telemetry, Ambient,
source visibility, both HUD views and notices are enabled in the supplied INI.
Unknown executables remain unsupported; automatic native compatibility is not
introduced. Older game executables require their corresponding older ASI package.

Live verification of the production-code candidate recorded **1,188 frames in
20 seconds**, **8,751 complete nine-ray targets**, fresh clear and blocked values,
and **116,478 API observations matched to native measurements**. The regular
release profile is built from that code; its exact ZIP was not reinstalled.
The owner waived repeated AN/AUS comparisons and a full historical manual retest.

**Limits:** source visibility remains a collision estimate, not optical light
transmission. Glass, cages and simplified collision geometry can differ from what
is visibly lit. Budget-limited, missing or stale results remain `unknown`.
One malformed filtered record observed in the live run was safely rejected.
The existing Ambient decoder is retained; a new bound-shader identity was not
independently established. Live HDR/other-GPU and physical Hue acceptance are
not newly claimed. See the validation record for the precise evidence.

Close the game before installing/updating. Import and activate/deploy the complete
**CrimsonDesertTelemetry-v2.2.6-ModManagers.zip**; keep all six runtime files from
the same package. Requirements remain .NET 8 ASP.NET Core Runtime (x64) and an
x64 ASI loader. Optional CrimsonHue is installed separately and additionally
requires .NET 8 Desktop Runtime (x64).
