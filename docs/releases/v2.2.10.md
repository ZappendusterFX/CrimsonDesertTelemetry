# Crimson Desert Telemetry 2.2.10 — Independent lighting controls

The shared mixer now supports **Hue, OpenRGB and Tuya LAN** through the separately installed [CrimsonHue 2.0.0](https://github.com/ZappendusterFX/CrimsonHue/releases/tag/v2.0.0). The Setup page lets you enable any combination. The Tuya LAN tab adds device setup, room placement and per-lamp status. Only Hue output needs a Hue bridge. CDT remains usable on its own for the API, radar and light markers.

**Automatic recovery verified on Steam build 26448710** (EXE 1.0.0.3549). The owner-installed candidate recovered against reference build 26423880, reached ready, and produced advancing camera-paired lights, Ambient, activity and physics visibility results. An independent scan matched all 30 cached addresses and guards. The packaged native reference remains **26423880**. Recovery covers compatible changes and can refuse a changed layout.

Simulation pause and capture resume remain available. The controller-specific Skills-menu issue remains open.

With the game closed, import and activate **CrimsonDesertTelemetry-v2.2.10-ModManagers.zip** using your mod manager. Keep the runtime files from the same package together. Requires **.NET 8 ASP.NET Core Runtime x64** and an x64 ASI loader. For optional lighting, install CrimsonHue 2.0.0 and **.NET 8 Desktop Runtime x64**.
