# Crimson Desert Telemetry 2.2.1

This update fixes the synchronized visibility flashes seen in 2.2.0 and improves
native capture with ReShade. It also includes the local ManyLights RGB bridge used
by a separate lightshow companion.

- **Visibility:** Continuous physics rays now use the validated game-query
  context. The owner confirmed the focused private fix removed the mass-flash
  pattern. Individual moving lights can still flicker; this is a separate open
  issue. Raw and smoothed light RGB are unchanged.
- **ReShade:** Native capture recognizes the same D3D12 device when ReShade 6.8
  exposes it through a proxy. Different devices still fail closed. This was
  verified with ReShade in an offline D3D12 test.
- **Capture startup:** CDT retains its probe command queue through process life
  and logs each preparation stage. A hung-game dump found the worker blocked while
  releasing that queue. The change removes that call from world entry; repeated
  live starts are needed to judge the sporadic hang.
- **Companion bridge:** A local companion can temporarily change ManyLights RGB.
  It disengages after an expired heartbeat and leaves normal light capture alone
  when inactive. The separate companion is not included in this ZIP. Persistent
  light switching is not part of this release.

The target remains Crimson Desert patch **2.03.02** on Steam for Windows (EXE
`1.0.0.2976`, Steam build `25477059`). HTTP API v1, snapshot schema 1.6 and the
production INI defaults are unchanged. Unknown game executables remain unsupported.

To upgrade, close the game and import the complete `ModManagers.zip` in DMM. DMM
3.1.1 has reproduced a removal failure that leaves the two Telemetry DLLs and two
lowercase CFG companions behind. After removing an old package, check those four
files in the DMM library and game `bin64` before importing the new ZIP; keep the
ASI loader and back up a customized INI. [Installation details](../../README.md).

**Validation:** package checks, the managed Release suite and all 37 production
native tests passed. The sporadic capture-start hang is not proven resolved.
[Validation record](v2.2.1-validation.md).
