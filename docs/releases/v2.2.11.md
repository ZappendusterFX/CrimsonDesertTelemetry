# Crimson Desert Telemetry 2.2.11 — Menu Detection and Direct Startup

- Starts directly on Steam build **26448710** (EXE **1.0.0.3549**) after the executable and code guards pass. Guarded recovery remains available for compatible future updates.
- Uses the game's verified menu state to pause light, ambient and visibility acquisition and activate optional CrimsonHue menu lighting in Skills. On exit, CDT resumes with fresh capture data.
- Keeps acquisition enabled in the tested cutscene, Kuku Shop and Kuku Pot crafting screens. These can stall simulation ticks while the guarded menu control stays closed.
- Keeps simulation tick observation independent. The activity API exposes it as `simulationState` while preserving the existing CrimsonHue integration.
- Resolves and verifies the menu control after compatible address changes. Acquisition stays enabled when the menu signal is unavailable.

With the game closed, import **CrimsonDesertTelemetry-v2.2.11-ModManagers.zip** into your mod manager. Keep the runtime files from the same package together. CDT requires **.NET 8 ASP.NET Core Runtime x64** and an **x64 ASI loader**. Optional lighting uses **CrimsonHue 2.0.0**.
