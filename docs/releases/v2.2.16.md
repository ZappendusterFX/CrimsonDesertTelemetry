# Crimson Desert Telemetry 2.2.16

Restores automatic recovery after the Crimson Desert update to Steam build
**26949954** (EXE **1.0.0.3840**). CDT checks the shifted renderer command
slots and finds the relocated visibility-ray call within a bounded search.
The owner confirmed the production-profile candidate in-game.

The optional **CrimsonHue** panel now starts hidden and leaves the game's
startup keyboard input available. Press **Ctrl+Shift+H** to open it, or use
your saved shortcut.

Close the game and import **CrimsonDesertTelemetry-v2.2.16-ModManagers.zip**
through your mod manager. Keep the package's files together. Requires an
**x64 ASI loader** and the **.NET 8 ASP.NET Core Runtime x64**. An existing
compatible CrimsonHue installation can be reused.

[Installation guide](https://github.com/ZappendusterFX/CrimsonDesertTelemetry/tree/v2.2.16#install-or-upgrade)
